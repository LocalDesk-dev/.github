# Contributing to LocalDesk

Thanks for your interest. Here's what's open today, and what isn't yet.

## Today

LocalDesk's source is not public yet, so there's nothing to send pull requests to. The most useful
contributions right now are reports from people using Early Access:

- **Bugs.** Open an issue in [`localdesk-public`](https://github.com/LocalDesk-dev/localdesk-public/issues/new/choose)
  with what you did, what you expected, what happened, and your LocalDesk and macOS versions.
- **Workflows.** Tell us an outcome you wanted LocalDesk to handle and where it fell short.
  Concrete repositories and tasks are more useful than feature names.

Before filing, please search existing issues.

## Security issues

Never in public issues. See [SECURITY.md](SECURITY.md).

## When the source preview opens

Code contribution guidelines, the license, and build instructions will ship in the source repository
itself. Until then, this file is the whole policy.
