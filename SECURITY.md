# Security Policy

This policy applies to every public repository in the LocalDesk-dev organization that doesn't carry its own.

## Reporting a vulnerability

Please **do not** report security issues in public GitHub issues, discussions or pull requests.

Report them privately through
[GitHub private vulnerability reporting](https://github.com/LocalDesk-dev/localdesk-public/security/advisories/new).
Include:

- What the issue is and its impact
- Steps to reproduce, or a proof of concept
- The LocalDesk version and macOS version you tested on

We'll acknowledge your report and keep you updated until it's resolved. Please give us a reasonable
chance to fix the issue before disclosing it publicly.

## Scope

In scope: the LocalDesk desktop app and any code published in this organization.

Out of scope: third-party services LocalDesk connects to (model providers, MCP servers you add), and
findings that require an already-compromised machine.

## Supported versions

Only the latest Early Access release receives security fixes.

## How LocalDesk handles security

See [localdesk.dev/security](https://localdesk.dev/security) for workspace boundaries, approvals and
where work runs.
