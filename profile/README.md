### Why LocalDesk

Most AI coding tools stop at generated code. Running it, checking it and deciding whether it's done still falls to you. LocalDesk is built to carry that last mile in your own environment, with the important decisions left to you.

### How it works

| Layer | Role |
|:--|:--|
| **Baymax** | The assistant. Turns what you want into a Mission. |
| **Mission** | The plan: steps, approvals and the checks that decide whether the work succeeded. Driven by MissionOS. |
| **Orbit** | The workspace where the work runs: repository, terminal, changes and verification. |

A native Rust + Tauri 2 runtime with a React and TypeScript interface. Models come from external providers through secure adapters; LocalDesk does not train its own foundation model.

| Stage | Details |
